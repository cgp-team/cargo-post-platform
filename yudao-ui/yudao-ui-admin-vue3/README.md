# 客货邮运营管理平台管理端

本目录被选定为唯一管理端，技术目标为 Vue 3 + TypeScript + Element Plus。

当前主仓库只包含上游说明与少量零散源码，不包含 `package.json`、lockfile、请求封装实现和应用入口，因此尚不是可独立构建的完整前端。接入完整管理端仓库后，应保留本目录新增的 `src/api/transport` 与 `src/views/transport` 骨架，并将浏览器标题、登录页名称和项目显示名称统一设置为“客货邮运营管理平台”。Logo 等待设计资源后替换。

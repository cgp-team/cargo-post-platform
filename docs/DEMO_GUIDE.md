# 客货邮平台 — 完整演示流程指南

> **适用场景：** 用户在小程序下单寄货 → 后台调度可视化 → 司机端看调度通知 → 用户端看司机到达通知

---

## 一、演示前准备

### 1.1 确保后端服务运行正常

`ash
# 进入部署目录
cd /opt/cargo-post-platform

# 启动所有服务（MySQL、Redis、后端 Java 服务）
docker compose -f deploy/docker-compose.yml up -d

# 验证后端 API 可用（应返回 JSON 而非报错）
curl http://localhost:48080/admin-api/infra/health
`

### 1.2 确保小程序已配置好

- 微信开发者工具已导入 miniprogram/ 目录
- miniprogram/config.js 或 project.config.json 中的 API 地址指向后端服务器
- 如使用体验版/正式版，需在微信公众平台配置服务器域名白名单

### 1.3 确保已有演示数据

按顺序执行以下 SQL 脚本（在 MySQL 容器内执行）：

`ash

  --default-character-set=utf8mb4 -u root -p"\" "\"

# 按顺序执行：
`

|:---:|---|---|
| 1 | sql/mysql/transport-demo-data.sql | 核心演示数据：站点（8个）、车辆（5台）、司机（5位）、司机-车辆绑定 |

## 二、用户端（小程序）下单

> **截图位置：** 寄件页面，包含寄件人、收件人、站点选择等表单

## 三、后台调度操作

### 3.1 登录后台管理系统

1. 浏览器打开后台管理地址（如 http://localhost:80 或部署服务器地址）
2. 输入账号：dmin，密码：dmin123
3. 点击"登录"

> **截图位置：** 后台登录页面

### 3.2 进入"调度中心"

1. 左侧菜单栏找到 **"运输管理"** → **"调度中心"**
2. 点击进入调度中心页面

> **截图位置：** 左侧菜单展开，"运输管理"分组下的"调度中心"菜单项

### 3.3 在订单池中查看新订单

1. 调度中心页面默认显示"订单池"标签页
2. 可以看到刚才用户下单的订单（状态为"待调度"）
3. 订单列表包含：订单号、寄件站点、收件站点、货物信息、下单时间等

> **截图位置：** 订单池列表，新订单高亮显示

### 3.4 点击"归集入池"

1. 勾选需要调度的订单（或点击"全选"）
2. 点击页面上方的 **"归集入池"** 按钮
3. 系统将订单标记为"已入池"，等待调度

> **截图位置：** "归集入池"按钮，订单状态变为"已入池"

### 3.5 点击"一键演示"按钮

1. 在订单池页面，找到 **"一键演示"** 按钮
2. 点击后系统自动生成调度方案（调用后端算法服务）
3. 等待调度完成（通常 3-10 秒）

> **截图位置：** "一键演示"按钮，加载动画

### 3.6 查看调度结果可视化

调度完成后，系统自动弹出 **"调度结果可视化"** 对话框：

#### 按车辆视角（默认）

- 左侧地图显示每辆车的行驶路线（不同颜色区分）
- 右侧面板显示每辆车的经停站点、操作类型（发车/揽收/派送/返场）、预计到达时间
- 地图右上角有图例：蓝色实线 = 真实道路，橙色虚线 = 直线估算

> **截图位置：** 调度可视化对话框，"按车辆"标签页

#### 按订单视角

1. 点击右侧面板的 **"按订单（含联运衔接）"** 标签
2. 左侧地图切换为选中订单的分段路线（不同颜色 = 不同车辆）
3. 右侧面板显示每个订单的运输段：哪一段由哪台车承运、在哪个站点换乘
4. 每个运输段旁标注 **"真实道路"**（蓝色标签）或 **"直线估算"**（橙色标签）
5. 如有估算路段，订单卡片顶部会显示黄色提示条："部分路段为直线估算，非真实道路轨迹"

> **截图位置：** 调度可视化对话框，"按订单"标签页，运输段标签

### 3.7 审核并下发方案

1. 在可视化对话框中确认方案合理
2. 关闭可视化对话框
3. 在调度方案列表中，找到刚生成的方案
4. 点击 **"审核"** 按钮，选择"通过"
5. 点击 **"下发"** 按钮，将方案下发给司机

> **截图位置：** 调度方案列表，"审核"/"下发"按钮

## 四、司机端操作

### 4.1 用司机手机号登录小程序

1. 退出当前用户账号
2. 切换到 **"密码登录"** 模式
3. 输入司机手机号（根据可视化对话框中显示的司机手机号）：
   - 调度方案中的第一条线路对应司机：13800138001（周建国）
   - 第二条线路对应司机：13800138002（李伟民）
   - 以此类推
4. 密码统一为：123456
5. 点击"登录"

> **说明：** 系统通过登录手机号自动匹配司机身份，无需额外选择。

### 4.2 进入"工作台"

1. 登录后，底部 Tab 栏出现 **"工作台"** 标签（仅司机可见）
2. 点击进入工作台页面

> **截图位置：** 司机工作台页面，显示待执行任务列表

### 4.3 查看调度通知和任务详情

1. 工作台页面显示 **"新任务通知"** 提示
2. 点击通知或任务卡片，查看任务详情：
   - 线路名称（如"渝B·B5201 线路"）
   - 经停站点列表（按顺序）
   - 每个站点的操作类型和货物信息
   - 预计出发时间

> **截图位置：** 任务详情页，站点列表

### 4.4 确认接单

1. 在任务详情页底部，点击 **"确认接单"** 按钮
2. 系统提示"已接单"
3. 任务状态变为"待执行"

> **截图位置：** "确认接单"按钮，状态变更提示

### 4.5 按站点顺序执行任务

1. 任务列表显示当前任务的下一个待执行站点
2. 到达站点后，点击 **"到达"** 按钮
3. 根据操作类型：
   - **揽收：** 扫描/输入包裹条码，确认揽收数量
   - **派送：** 确认签收人信息，完成派送
4. 完成后自动跳转到下一个站点

> **截图位置：** 站点操作页面，揽收/派送确认弹窗

## 七、常见问题排查

### Q1: 小程序登录失败（500 错误）

**原因：** 短信验证码渠道未配置

**解决：** 使用"密码登录"模式，不要用短信验证码登录。

### Q2: 一键演示按钮不可用/无反应

**原因：** 订单未入池，或算法服务未启动

**解决：**
1. 确保订单已执行"归集入池"操作
2. 检查算法服务是否运行：docker compose logs algorithm

### Q3: 可视化对话框地图不显示

**原因：** 百度地图 SDK 加载失败（无网络/无 API Key）

**解决：** 系统会自动切换为"坐标示意图"模式（SVG 绘制），功能不受影响。如需真实地图，配置百度地图 API Key。

### Q4: 路线显示为直线而非真实道路

**原因：** 高德地图路径规划 API 不可用

**解决：**
- 系统会自动重试（30 秒冷却期后再次请求）
- 直线段在地图中以虚线显示，右侧面板标注"直线估算"
- 不影响调度方案的正确性，仅影响路线展示精度

### Q5: 司机端看不到任务

**原因：** 登录手机号与调度方案中分配的司机不匹配

**解决：** 查看调度可视化对话框中每条线路的司机手机号，用对应手机号登录。

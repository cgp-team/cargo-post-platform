# 团队协作与职责

## 运维与系统集成负责人

负责仓库与分支规则、Docker 和部署、CI/CD、算法接口协议、Mock 算法服务，以及测试、日志、备份和交付。环境配置使用密钥管理或部署变量，不提交 `.env`。

## 前端负责人

负责 Vue 管理端、GIS 地图、数据大盘、调度工作台、动态权限菜单和接口联调。Vue3 管理端已完整接入（`yudao-ui-admin-vue3/src/views/transport/` 下含 dashboard、monitoring、dispatch、order、vehicle、driver、station、route、shift、settlement、operation 等页面），后续改动沿用现有骨架与产品标题。同时负责微信小程序（`miniprogram/`，含商城、寄件、包裹等用户端页面与司机工作台），小程序只调用 `/app-api`，与管理端一样不得直连算法服务。

## 后端负责人

负责 transport 模块、数据库、业务接口、订单和调度状态机、算法适配层、算法结果合法性校验。跨模块依赖必须通过明确服务/API，不把业务实现放入 system 或 infra。

## 算法组

负责路径规划模型、算法服务、算法版本、调度结果、评价指标和拒单原因。算法输入只使用业务后端提供的快照，不直接读取或修改业务数据库。

## 分支与评审

- 功能分支按 `feat/*`、修复按 `fix/*`、工程维护按 `chore/*`。
- 数据库、状态机和算法协议变更至少需要后端与系统集成双人评审。
- PR 必须说明迁移、回滚、测试和未决风险；禁止混入无关格式化。

# 人工测试清单（微信开发者工具 / 真机）

> 需开发者工具"详情→本地设置→不校验合法域名"勾选；后端地址 `http://1.15.29.107/api`。

## A. 定位（首页）

- [ ] A1 首次进入授权定位：顶部村庄名=逆地理区域，无报错
- [ ] A2 拒绝定位：显示"开启定位后，可查看附近公交"，点提示走"去设置"，返回后可继续
- [ ] A3 定位失败（关定位开关）：显示"定位不可用"，首页其余功能正常
- [ ] A4 缓存秒出：二次进入立即显示村庄名，后台刷新
- [ ] A5 **切换村庄**：切"青山镇"→ nearby 按青山镇刷新（当前 master 有 bug，见 BUG-002）

## B. 附近公交（首页）

- [ ] B1 有公交：显示线路/班次/起终点/状态/下一站/数据来源/ETA
- [ ] B2 无公交（农村）：显示"附近暂无实时公交"
- [ ] B3 接口失败（断网/后端停）：显示"实时公交暂时不可用"+重新加载可恢复
- [ ] B4 15s 自动刷新：停留观察，更新时间文案变化
- [ ] B5 页面隐藏/返回：onHide 停刷新，onShow 恢复，无重复请求（Network 面板确认）
- [ ] B6 下拉刷新：立即刷新一次
- [ ] B7 真实定位 vs 模拟：REAL 车辆标"实时"，SIMULATED 标"模拟位置"

## C. 寄货（send 页）

- [ ] C1 站点选择器：点取货/送达打开弹窗，搜索/勾选/取消/关闭正常，展示地址
- [ ] C2 相同站点：取货=送达拦截提示
- [ ] C3 路线预览：点"下一步"显示真实距离/分钟，失败显示"暂时无法获取路线"+重新查询
- [ ] C4 停用站点：管理端停用后，寄货提交被后端拒绝
- [ ] C5 完整流程：选站→预览→拍照→确认发布→订单成功（二维码）
- [ ] C6 直接构造 API：POST /send/create 传非法/停用/相同站点 → 后端拒绝

## D. 实时公交（bus 页）

- [ ] D1 bus/index：线路选择/地图 marker/车辆列表 15s 刷新
- [ ] D2 bus/detail：车辆信息/进度/经停状态；无位置显示"暂时无法获取车辆实时位置"
- [ ] D3 真实上报车辆：司机上报后显示实时位置（REAL_FRESH）

## E. 异常

- [ ] E1 断网进首页：天气兜底、公交错误态、商品空态，不崩溃
- [ ] E2 后端 500：接口返回错误态，可重试
- [ ] E3 算法服务停：公交 ETA 不显示，页面正常
- [ ] E4 高德配额：算法降级直线，前端标注"模拟位置/位置暂不可用"

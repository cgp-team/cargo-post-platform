农村客货邮小程序 · 设计审查 & 改版对比

审查范围：miniprogram/ 全部 20 个页面（纯手写样式，无 UI 组件库）。整体上项目有难得的主题意识（「站牌与车票」概念、4 套换肤变量、适老化体系），但执行层存在明显的一致性问题。 下方左侧手机为现状还原（按真实 wxml/wxss 的色值、布局、emoji 图标复刻），右侧为改版方案，中间/旁边卡片为逐条批注。核心结论：

问题 1导航样式三轨并存

app.json 全局导航是黑色 #1A1A1A，但首页/商城/快递/我的又是自定义绿色渐变头，send 是原生绿导航。从首页点进「我的订单」像换了 App。

问题 2emoji 当图标和商品主图

tabBar 🏠🛒📦👤、功能入口、商品主图（100–180rpx 的 emoji）全靠 emoji 渲染（goods.wxml:59），跨平台显示不一致，是"简陋感"最大来源。

问题 3色彩语义混乱

天气卡是全 App 唯一的蓝色模块（index.wxss:140）；价格一会陶土橙（首页）一会 Material 红 #E53935（商城/详情），红色与「退出登录」撞语义。

问题 4首页信息过载

顶栏+搜索+天气(含4日预报)+公告+四宫格+快捷条+公交+商品+FAB 共 9 个模块，且「四宫格」与「快捷操作」内容重复（公交/农产品/快递出现两次）。

问题 5低对比度小字普遍

20rpx 灰字（#757575/#888/#999）遍布各页，对比度约 2.8:1，远低于 WCAG 4.5:1——对农村中老年用户尤其不友好，与项目自身的适老化目标矛盾。

问题 6设计规范无 token 约束

字号散落 17+ 档、圆角 14 种、阴影 10+ 种手写值；卡片底色三种白并存；还有同色假渐变、死 CSS 等残留。

思路保留什么

保留「站牌与车票」签名元素（车票撕口卡、虚线路）、绿/橙/金/米纸色板、主题变量架构、适老化与司机端大按钮设计——这些是项目的辨识度所在。

思路改进什么

统一绿色导航；SVG 图标 + 真实商品图替换 emoji；价格统一陶土橙、天气卡收回主题色系；首页收敛为 6 个模块；建立字号/圆角/阴影 token；小字提级到 22rpx+ 且加深颜色。

① 首页 — 信息收敛与主题统一

现状：9 个模块堆叠、内容重复、蓝色天气卡出戏、常驻 FAB 遮挡内容。改版：天气并入主题色系且瘦身为单行，四宫格去掉重复入口和冗余描述，快捷条与 FAB 取消，整体收敛为「头部 + 搜索 + 公告 + 四宫格 + 公交 + 农产品」6 块。

④ 设计规范沉淀 — 从"口口相传"到 token

现状字号 17+ 档、圆角 14 种、阴影 10+ 种手写值、三种卡片白。建议收敛为下表，全部落进 app.wxss CSS 变量（项目已有变量机制，补齐即可）：

色板语义化扩展

保留 --color-primary/paper/clay/gold，新增 --color-price = clay、--color-status-*（待付款=clay / 运输中=green / 已完成=gray / 提醒=gold）、--color-danger（仅用于退出/删除，与价格解耦）。

字号6 档收敛

标题 34 / 卡片标题 30 / 正文 26 / 辅助 22 / 角标 20 / 大数字 40（rpx）。废止 20rpx 以下和 #999 以下的辅助文字——适老化基线：辅助文字 ≥22rpx 且 ≥ #6b675c。

圆角4 档收敛

--radius-s:8（小件）/ --radius-m:16（卡片）/ --radius-l:24（弹窗）/ --radius-pill:999；保留车票卡的 16-8-8-16 不对称圆角作为签名例外。

阴影2 档收敛

卡片 0 2rpx 12rpx rgba(60,50,30,.06)（暖棕，贴合纸感）；浮层 0 8rpx 24rpx rgba(60,50,30,.12)。删除中性黑阴影。卡片底色统一 #FFFDF8。

图标SVG 组件化

建 components/icon，内置 20 枚线性 SVG（本页左栏即为候选图标集）；tabBar、功能入口、菜单、空态全部接入，emoji 仅保留在内容性场景（如公告表情）。

导航全局一行修复

app.json：navigationBarBackgroundColor → #1C4B2E，各页 json 的 backgroundColor #F5F5F5 统一为 #F6F2E9。司机端保留独立暗黑主题（场景合理），但绿色系内统一。

⑤ 本次未展开但建议同步处理的

文案自洽

同一车辆状态三处措辞不一：「已到站 / 待发车 / 行驶中」混用（bus/index.wxml:67 vs bus/detail.wxml:9）；取件码在列表卡平铺暴露（parcel.wxml:96），建议折叠进详情或点击可见。

代码卫生

同色假渐变 4 处（detail.wxss:66 等）、死 CSS（send.wxss:175-230）、app.json tabBar selectedColor 与 custom-tab-bar 实际色值两处定义可能漂移。

适老化不均

.elderly-mode 覆盖规则逐页手写且各页覆盖类数不一（orders 6 个 vs index 24 个），建议改为全局密度变量驱动，一处定义全站生效。
